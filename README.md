# app-ponente

Página sencilla en HTML + [Bootstrap 5](https://getbootstrap.com/) para el **Taller de GitHub**.

## Estructura

```
app-ponente/
├── index.html      # Página principal
├── css/styles.css  # Estilos propios
└── js/main.js      # Agenda dinámica y validación del formulario
```

## Cómo verla

Abre `index.html` en tu navegador (doble clic). No necesita instalar nada:
Bootstrap se carga desde un CDN.

## Ideas para practicar en el taller

1. Crea una rama: `git switch -c agrega-tema`
2. Agrega un tema nuevo al arreglo `agenda` en `js/main.js`
3. Haz commit, push y abre un Pull Request
